ABOUT THE PROJECT

Understanding HeartCare

A machine learning application designed to classify patient records according to the presence or absence of heart disease.

♥
⌁

Machine Learning Model

HeartCare uses a trained Logistic Regression classification model to analyse patient information and generate predictions.

▤

Dataset

The system uses the hospital synthetic dataset used during model development and training.

♥

Prediction Target

The target variable is heart_disease. The model predicts either class 1 or class 0.

◷

Patient Records

Previous patient information and prediction outcomes are stored in a local SQLite database for future reference.

Important Notice

HeartCare is an academic machine learning project. Its predictions are not a substitute for professional medical examination, clinical testing or advice from a qualified healthcare professional.
